# Usage Guide

Practical workflows to maximize productivity and token efficiency in GraphFinder:

## 1. Creating and Connecting Notes
- To connect notes, use the standard wikilink syntax `[[Note Title]]`.
- Example: Link directly to [[Architecture]] or return to [[Welcome]].
- The interactive 2D graph updates in real time as you type.

## 2. Tags and Categorization
- Add contextual hashtags such as `#research`, `#project`, or `#architecture` to your notes.
- The graph canvas groups and visualizes nodes by color based on their dominant tag clusters.

## 3. Operating via MCP
- AI agents query your knowledge vault using surgical atomic tools (`search_semantic`).
- Agents receive precise deep links like `[[Note#Section]]` consuming ~50 tokens rather than whole files.
- Check our RAG foundations in [[AI Concepts and RAG]].
