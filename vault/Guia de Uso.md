# Guia de Uso

Como tirar o máximo proveito do GraphFinder:

## Como criar links
- Para conectar esta nota a outra, utilize a sintaxe `[[Nome da Nota]]`.
- Exemplo: conecte de volta para a [[Arquitetura]] ou para as [[Boas-vindas]].

## Tags e Categorização
- Adicione hashtags como `#estudo`, `#projeto`, `#ideia` no texto.
- O grafo agrupará nós visualmente por cores baseadas em suas tags predominantes.

## Usando via MCP
- Agentes de IA podem pesquisar semânticamente seu cérebro de notas.
- Quando a IA armazena um contexto, ela pode referenciar notas existentes ou criar novas arestas automaticamente.
