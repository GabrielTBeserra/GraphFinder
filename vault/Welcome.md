# Welcome to GraphFinder

GraphFinder is a local-first knowledge management system powered by an interactive graph and local vector search.

## What Makes GraphFinder Unique?
- **Local Semantic Retrieval**: Discover notes by conceptual meaning, not just exact keywords.
- **Bidirectional Graph**: Connect ideas naturally through [[Architecture]].
- **Zero Telemetry**: All AI vector processing runs locally on your machine with zero cloud dependencies.

## Getting Started
1. Explore connections in the interactive graph canvas.
2. Create new notes using the `[[Note Title]]` syntax to link concepts.
3. Follow the [[Usage Guide]] to configure the embedded MCP server for your AI coding assistants.
4. Read [[AI Concepts and RAG]] to understand our atomic chunking model.
