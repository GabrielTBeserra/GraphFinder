Recursos

Um motor para notas, código e agentes.

Tudo roda na sua máquina: um núcleo em Rust com modelo ONNX embarcado, SQLite com FTS5, uma interface de grafo force-directed e um servidor MCP com o qual qualquer editor de IA conversa.

Busca semântica híbrida

Vetores densos FastEmbed de 384 dimensões combinados com BM25 do SQLite FTS5 via Reciprocal Rank Fusion (k = 60). As notas são divididas por títulos ##/###, então cada resposta é uma seção atômica com deep link, como [[Nota#Seção]].

FastEmbed ONNXSQLite FTS5RRF k=60AST pulldown-cmark

100% local

Sem API keys, sem telemetria. Seu Markdown continua como arquivos simples no disco.

Grafo interativo

Canvas force-directed com destaque de vizinhança de 1/2 saltos, clusters por tag e anéis coloridos por linguagem.

Inteligência de código

Varredura AST-lite de repositórios inteiros: símbolos (funções, classes, structs), grafo de imports locais e pacotes externos — respeitando o .gitignore e sincronizando de forma incremental por SHA-256.

TypeScript Rust Python Go JavaScript C / C++ Java · Kotlin · C# + outras

Servidor MCP nativo

24 ferramentas via Streamable HTTP/SSE (127.0.0.1:45123) com o app aberto, ou stdio headless com graphfinder mcp. Funciona com Cursor, Claude Desktop, Antigravity, Windsurf, Cline, Roo Code e Zed.

Análise de grafos

Detecção de comunidades, centralidade de grau, God Nodes, acoplamentos surpresa, ciclos e caminhos mínimos — exportados como graph.json, GRAPH_REPORT.md e um graph.html offline.

Monitoramento ao vivo

Edite no Obsidian, VS Code ou Neovim — as mudanças são reindexadas em 500 ms.

Múltiplos projetos

Vaults isolados, cada um com seu índice. Renomear atualiza todos os wikilinks de entrada.

Seguro por padrão

Defesa contra DNS rebinding, validação de Origin, CSP estrita e sanitização com DOMPurify.

01Visão geral#

O GraphFinder é um aplicativo desktop multiplataforma (Tauri v2 + Rust + React 19) e uma ferramenta de linha de comando que indexa vaults de conhecimento em Markdown e repositórios de código em um único grafo pesquisável semanticamente.

Pipelines de RAG tradicionais cortam documentos em janelas fixas arbitrárias ou jogam arquivos inteiros no contexto do LLM, desperdiçando milhares de tokens. Já as ferramentas de notas raramente oferecem busca vetorial local ou uma API utilizável por agentes. O GraphFinder resolve os dois lados:

  • Para humanos — um ambiente local-first e sem distrações para escrever Markdown puro com [[wikilinks]], explorar conexões em um grafo 2D interativo e manter total posse dos seus arquivos.
  • Para agentes de IA — um servidor Model Context Protocol (MCP) embarcado que retorna resultados no nível de subseção ([[Nota#Seção]]) e símbolos de código individuais, tipicamente com cerca de 50 tokens por resultado.

Conceitos principais

ConceitoSignificado
VaultUma pasta de arquivos .md (e opcionalmente código) indexada pelo GraphFinder.
ProjetoUm vault registrado com seu próprio índice SQLite isolado. Identificado por um slug (ex.: minha-api).
ChunkUma seção atômica de uma nota delimitada por títulos ## / ###, vetorizada de forma independente.
Deep linkReferência a uma seção específica: [[Título da Nota#Título da Seção]], ou a um símbolo: [[caminho/arquivo.rs#funcao]].
Nó / ArestaNotas e arquivos de código são nós; wikilinks e imports são arestas.
God NodeUm hub altamente central no grafo, detectado por centralidade de grau.

02Instalação#

Opção A — Instaladores prontos (recomendado)

Cada release com tag é compilada pelo GitHub Actions para as três plataformas desktop. Baixe a mais recente na página de Releases:

Windows.exe (NSIS) · .msi (WiX) macOS.dmg (Apple Silicon) Linux.deb · .AppImage

Após instalar, habilite o comando de terminal para que graphfinder funcione em qualquer shell:

bash
# Windows: adiciona a pasta de instalação ao PATH do usuário + cria atalhos graphfinder.cmd
# macOS/Linux: cria um symlink em ~/.local/bin/graphfinder
graphfinder install-cli

Se graphfinder ainda não estiver no PATH, execute o binário diretamente, ex.: "C:\Program Files\GraphFinder\GraphFinder.exe" install-cli. Depois abra um novo terminal.

Opção B — Compilar a partir do código-fonte

Pré-requisitos

  • Node.js 20+ e npm
  • Rust 1.75+ via rustup
  • Windows: Visual Studio C++ Build Tools · Linux: libwebkit2gtk-4.1-dev, build-essential, libssl-dev, libayatana-appindicator3-dev, librsvg2-dev
bash
git clone https://github.com/GabrielTBeserra/GraphFinder.git
cd GraphFinder
npm install

# Roda o app desktop em modo de desenvolvimento (Vite na :1420 + Tauri)
npm run app

# Gera instaladores em src-tauri/target/release/bundle/
npm run tauri build

Na primeira execução o modelo de embeddings (all-MiniLM-L6-v2, ~90 MB) é baixado uma única vez para .fastembed_cache. Depois disso o GraphFinder funciona totalmente offline.

  1. Abra o appInicie o GraphFinder (ou rode graphfinder sem argumentos). Um vault padrão é criado e o grafo aparece.
  2. Crie ou abra um projetoUse o seletor de projetos na barra superior → Novo projeto, dê um nome e, opcionalmente, escolha uma pasta existente (de notas ou um repositório de código).

cd ~/code/meu-projeto

05Escrevendo notas#

O GraphFinder funciona com qualquer Markdown, mas a recuperação fica mais precisa quando as notas seguem esta estrutura:

  1. Um único título H1 (# Título da Nota) seguido de um resumo executivo de 2–3 linhas.
  2. Seções ##/### autocontidas de aproximadamente 40–150 tokens, com títulos descritivos (## 2. Configuração do SQLite WAL em vez de ## Config). Cada título vira um embedding próprio e um alvo de deep link.
  3. Wikilinks — [[Nota]] ou [[Nota#Seção]]. Mire em 1–3 links por nota para evitar órfãos.
  4. Hashtags em minúsculas — #arquitetura #sqlite #mcp no fim das seções ou da nota. Elas geram os clusters coloridos no grafo.
vault/Auth JWT.md
# Auth JWT

Como a API emite e valida JSON Web Tokens. Cobre chaves de assinatura,
política de expiração e rotação de refresh.

## 1. Assinatura de Tokens
Os tokens são assinados com RS256. As chaves giram a cada 30 dias e são
carregadas do cofre de segredos na inicialização. Veja [[Arquitetura do Sistema#2. Segredos]].

## 2. Rotação de Refresh
Cada refresh invalida a família de tokens anterior para impedir ataques de replay.

#auth #seguranca #arquitetura

Como as notas são processadas

  • O parsing usa uma AST CommonMark real (pulldown-cmark). O conteúdo dentro de blocos de código é isolado, então um # em código nunca é tratado como título ou tag.
  • Seções com mais de 320 tokens são divididas em janelas com sobreposição de 40 tokens para não perder contexto nas bordas.
  • Renomear uma nota (pela interface ou rename_note) reescreve todos os [[Título Antigo]] no vault.
  • Notas editadas fora do GraphFinder (Obsidian, VS Code, Neovim…) são detectadas pelo file watcher (debounce de 500 ms).

06Motor de busca#

Cada consulta executa dois mecanismos de recuperação em paralelo e os combina:

EtapaDetalhes
Vetores densosFastEmbed sobre ONNX Runtime. Modelo padrão all-MiniLM-L6-v2 (384 dimensões). Opcional MultilingualE5Small para vaults em outros idiomas. Similaridade de cosseno sobre note_chunks / code_chunks.
Palavra-chave (BM25)Índice full-text SQLite FTS5 — encontra identificadores exatos, códigos de erro e termos raros que embeddings deixam passar.
FusãoReciprocal Rank Fusion: score = Σ 1 / (60 + rank). Robusto sem normalização de scores.
SaídaTop-N chunks com título, seção, deep link, score de afinidade e estimativa de tokens.

O armazenamento é um único banco SQLite por projeto em modo WAL, permitindo indexação e consultas concorrentes. A reindexação é incremental: arquivos são comparados por timestamp e hash SHA-256, e apenas os alterados são reprocessados e revetorizados.

07Indexação de código#

Aponte o GraphFinder para um repositório e ele constrói um índice de símbolos e um grafo de dependências sem precisar de compilador ou language server.

Tipos de arquivo suportados

LinguagemExtensõesImports analisados
TypeScript / TSX.ts .mts .cts .tsximport, require
JavaScript / JSX.js .mjs .cjs .jsximport, require
Python.py .pyiimport, from … import
Rust.rsuse, mod
Go.goimport
C / C++.c .h .cpp .hpp .cc .cxx .hh#include
Java / Kotlin.java .kt .ktsimport
C# / F#.cs .fsusing
PHP · Ruby · Swift.php .rb .swiftuse/require/import
Web e configuração.html .css .scss .sass .less .json .yaml .toml .sqlindexados como arquivos
Shell.sh .bash .zshsource

O que é extraído

  • Símbolos — funções, classes, structs, interfaces e enums de nível superior, com intervalos de linha e estimativa de tokens. Cada símbolo é um chunk pesquisável.
  • Imports locais — resolvidos para arquivos do projeto e salvos como arestas bidirecionais (code_links): imports e dependentes.
  • Pacotes externos — módulos de terceiros (ex.: rusqlite, react) listados por arquivo.

O que é ignorado

Tudo que está no .gitignore, além de node_modules, target, dist, .git, arquivos binários e arquivos maiores que 1 MB.

08Análise de grafos#

Um motor de análise escrito em Rust puro trata notas e arquivos de código como um grafo unificado e responde perguntas de arquitetura.

AnáliseDescrição
ComunidadesClustering por propagação de rótulos / estilo Louvain revela subsistemas modulares.
Centralidade e God NodesA centralidade de grau ranqueia os nós; os hubs mais conectados são marcados como God Nodes — refatore ou documente-os primeiro.
Acoplamentos surpresaArestas que acoplam subsistemas distantes — frequentemente dívida arquitetural oculta.
CiclosCadeias de dependência circular entre arquivos.
Caminho mínimoBFS por imports e wikilinks entre dois nós quaisquer (graphfinder path, find_path).
Explicação de nóCartão 360°: comunidade, ranking de centralidade, quem chama, quem é chamado, irmãos (graphfinder explain, explain_node).

Artefatos exportados

graphfinder report, graphfinder export, sync --export ou a ferramenta export_graph gravam em ./graphfinder-out/:

  • graph.json — nós (comunidade, grau, centralidade, flag de god-node) e arestas (origem, destino, rótulo, peso). Ideal para agentes e scripts.
  • GRAPH_REPORT.md — resumo executivo, métricas, tabela de God Nodes, lista de subsistemas, acoplamentos surpresa e ciclos.
  • graph.html — visualizador offline sem dependências, com busca, cores por comunidade e halos nos hubs. Abra em qualquer navegador.

09Referência da CLI#

O mesmo binário é o app desktop e a CLI. Executado sem argumentos, abre a interface gráfica; com um comando, roda no terminal.

uso
graphfinder [COMANDO] [OPÇÕES]
Comando (aliases)OpçõesDescrição

status (info) [caminho]—Mostra notas, arquivos de código, arestas e estatísticas do banco.
projects (list)—Lista todos os projetos registrados e seus caminhos.

Exemplos

bash
# Sync com saída legível por máquina para CI ou scripts
graphfinder sync ./services/api --json

# Como a interface chega até a camada de banco?
graphfinder path "GraphView.tsx" "db.rs"

# Por que este arquivo é importante?

12Agentes de IA e skills#

O GraphFinder traz três camadas que trabalham juntas: o agente (Cursor, Claude, Antigravity…) raciocina e planeja, a skill impõe economia de tokens e qualidade das notas, e o servidor MCP executa buscas e escritas.

Skills e regras incluídas

  • AGENTS.md — regras do repositório para agentes (economia de tokens, schema de notas, pipelines de decisão). O Antigravity carrega automaticamente; no Cursor adicione às Project Rules; no Claude cole no prompt do projeto.
  • .agents/skills/graphfinder-curator — fluxo de autoria e curadoria (resumos, seções atômicas, suggest_links antes de store_context, tags).
  • .agents/skills/graphfinder — fluxo de auditoria de arquitetura (relatórios, caminhos, explain, exportações).

Fluxos recomendados

Respondendo uma pergunta

fluxo
search_semantic("sqlite wal mode")        → top 5 chunks (~50 tokens cada)
  └─ precisa da estrutura?  get_compressed_context("Arquitetura do Sistema")
  └─ precisa de uma seção?  read_section("Arquitetura do Sistema", "1. Armazenamento Local")

Salvando conhecimento

fluxo
rascunho (# Título + resumo + seções ##)
  → suggest_links(rascunho)                → ex.: "Arquitetura do Sistema: 85%"
  → inserir [[Arquitetura do Sistema]] no rascunho
  → store_context(title, content, tags)    → arquivo gravado, indexado, grafo atualizado

Inspecionando código

  → read_code_chunk("src-tauri/src/engine/db.rs", "hybrid_search")

13Projetos e vaults#

Cada projeto é um workspace isolado com seu próprio diretório Markdown e seu próprio banco vetorial SQLite, então as buscas nunca vazam entre projetos.

  • Vault padrão — <pasta de dados>/vault com índice em <pasta de dados>/index.db.
  • Vaults gerenciados — <pasta de dados>/vaults/<project_id>/, criados pela interface ou por create_project.
  • Pastas externas — qualquer caminho do disco (ex.: um repositório) registrado pela interface, por graphfinder sync <caminho> ou create_project(name, path).
  • Registro — vaults/projects.json guarda o projeto ativo, nomes e caminhos personalizados.
vaults/projects.json
{
  "active_project": "default",
  "custom_names": { "minha-api": "Minha API" },
  "custom_paths": { "minha-api": "C:/Repos/MinhaAPI" }
}

Onde fica a pasta de dados?

  1. GRAPHFINDER_DATA_DIR, se definida.
  2. O diretório atual, se contiver package.json (código-fonte / modo dev).
  3. Caso contrário, a pasta de dados do sistema: %APPDATA%\GraphFinder (Windows), ~/Library/Application Support/GraphFinder (macOS), ~/.local/share/GraphFinder (Linux).

16Segurança#

  • Somente loopback — o servidor MCP HTTP escuta apenas em 127.0.0.1.
  • Defesa contra DNS rebinding — o cabeçalho Host é validado em cada requisição.
  • Validação de Origin — middleware estrito em vez de CORS permissivo.
  • Content Security Policy — aplicada no tauri.conf.json.
  • Proteção contra XSS — previews Markdown são sanitizados com DOMPurify.
  • Proteção contra path traversal — ids de projeto são sanitizados antes de tocar o sistema de arquivos.

Reporte vulnerabilidades de forma privada conforme o SECURITY.md.

18Problemas e FAQ#

Meu agente não conecta em 127.0.0.1:45123.

O endpoint HTTP/SSE só existe enquanto o app desktop está aberto. Abra o app ou mude o cliente para o modo stdio ("command": "graphfinder", "args": ["--mcp"]). Se alterou GRAPHFINDER_MCP_PORT, atualize a URL.

graphfinder não é reconhecido no terminal.

Rode GraphFinder.exe install-cli (ou graphfinder config --install) e abra um novo terminal para carregar o PATH atualizado.

Os resultados são ruins para português / outros idiomas.

Defina GRAPHFINDER_MODEL=multilingual e reindexe.

A primeira inicialização é lenta.

O modelo de embeddings é baixado uma vez. Nas próximas execuções ele é carregado de .fastembed_cache; aponte GRAPHFINDER_MODELS para uma cópia local em máquinas sem internet.

Alguns arquivos não aparecem no grafo de código.

Verifique se estão no .gitignore, se são binários, se passam de 1 MB ou se têm extensão não suportada. Rode graphfinder sync para forçar uma atualização incremental.

Algum dado sai da minha máquina?

Não. Embeddings, busca e análises rodam localmente. O único acesso à rede é o download único do modelo (e este site consultando a release mais recente no GitHub).
